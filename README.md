# Komentár k zákonu č. 162/2015 Z. z., Správny súdny poriadok

Konsolidované znenie k **12. 6. 2026**, zdroj [slov-lex.sk](https://www.slov-lex.sk/static/SK/ZZ/2015/162/20260612.html).
